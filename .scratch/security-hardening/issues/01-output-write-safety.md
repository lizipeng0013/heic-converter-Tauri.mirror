# 01: 输出写安全——不覆盖、不跟随符号链接

**What to build:** 作为用户，我把转换结果写到输出目录时，永远不会静默覆盖已存在的同名文件，也不会因为目录里被预置了符号链接而改写我目录之外的文件；应用的可写性探测本身不再有"写后删"的攻击面。同名冲突时得到明确错误（或自动加序号），冲突文件双方都完好。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 输出文件已存在时写入失败并返回"输出冲突"类用户友好错误，或自动追加序号生成不冲突的文件名（二选一，实施时定）
- [x] 输出目标名被预置符号链接占用时不覆盖、不跟随，自动改用序号名称，被链接的原文件不被修改
- [x] 目录可写性探测改用"创建即失败"语义，探测失败直接返回错误，不再写入固定文件名探针后删除
- [x] 冲突与符号链接占用路径各有测试（tempfile 驱动，覆盖外部可观察行为；含悬空符号链接跳过、探测不跟随符号链接）
- [x] 正常写入路径的既有测试全部通过
