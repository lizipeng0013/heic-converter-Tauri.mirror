# 03: 命令层输入校验与输出目录约束

**What to build:** 作为用户，任何来自前端的转换请求都在 Rust 命令入口被真实校验：只有普通文件（FIFO/设备文件/目录被拒）、只有白名单扩展名、数量有上限、输出目录必须是应用已确认的目录（目录对话框选定或系统下载目录）。前端传来的任意路径不能再驱动"在任意位置创建目录树并写文件"。同批次中不同目录的同名文件不再竞争同一个输出文件。

**Blocked by:** 01 (输出写安全)

**Status:** done

- [x] 输入路径非普通文件（含 FIFO、设备、目录）时被拒绝，返回用户友好错误，转换线程不阻塞
- [x] 扩展名不在白名单、输入数量超过上限时被拒绝
- [x] 输出目录不在已确认集合内时被拒绝，不对该路径执行目录创建或写入
- [x] 同批次目标路径冲突者自动加序号或报错，两个源文件都产出完好的输出
- [x] 上述校验各有测试，覆盖外部可观察行为（给定输入 → 观察拒绝错误）
- [x] 正常批量转换流程（既有样例）不受影响
