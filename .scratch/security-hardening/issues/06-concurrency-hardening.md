# 06: 批次转换并发加固

**What to build:** 作为用户，连续多批转换时应用不会越跑越卡直至假死——批次执行不再占用异步运行时线程，通知没被点掉之前也不再占住转换线程；我点"停止"只停当前批次；已有批次在跑时再次发起转换会被明确拒绝而不是叠加并发；转换写盘途中应用不会被任意强制退出而留下截断文件，关闭确认无法被绕过。

**Blocked by:** 03 (命令层输入校验)

**Status:** done

- [x] 批次转换整体在阻塞线程上下文执行，async worker 不被长 CPU 任务占用
- [x] Linux 常驻通知的等待移出 async 上下文，通知未点掉不阻塞其他功能
- [x] 停止标志改为批次局部：停止 A 批不影响 B 批（或明确拒绝并行批次）
- [x] 单飞闸：已有批次在跑时新批次返回用户友好错误
- [x] 强制退出命令从 invoke 处理器移除（前端零调用），关闭确认只能走既有窗口关闭流程；有批次在跑时退出先经停止流程
- [x] 实机验证：连续多批转换 + 最小化窗口，应用保持响应
